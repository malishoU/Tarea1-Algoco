Los experimentos fueron realizados en un computador con procesador Intel Core i5-12500H 
de 12ª generación, con 16 procesadores lógicos y aproximadamente 7,6 GiB de memoria RAM 
disponible para el sistema. Las pruebas se ejecutaron utilizando WSL2 sobre Windows, con 
Ubuntu 24.04.4 LTS y kernel Linux 6.6.87.2. Los programas fueron implementados en C++17 y 
compilados utilizando g++ 13.3.0 con la opción de optimización \texttt{-O2}. Para la 
generación de los datasets y de las gráficas se utilizó Python 3.12.3.

Para los experimentos de ordenamiento se utilizaron arreglos de tamaños 10, 1000, 100000 y 
10000000, considerando arreglos aleatorios, ascendentes y descendentes, dos dominios de 
valores (D1 y D7) y tres muestras por configuración. Para la multiplicación de matrices 
se utilizaron matrices cuadradas de tamaños 16, 64, 256 y 1024, considerando matrices 
densas, diagonales y dispersas, los dominios D0 y D10 y tres muestras por configuración. 
En ambos experimentos se registró el tiempo de ejecución y el uso máximo de memoria de 
cada algoritmo.

Se agregó una semilla fija (20260911) a los generadores para poder repetir
los mismos datos al ejecutar los scripts completos en el mismo orden.
En matrices se fijó la semilla de NumPy y de \texttt{random}.
Las mediciones actuales son anteriores a este cambio; falta repetir las
pruebas y actualizar los resultados. Los tiempos pueden variar entre ejecuciones.

Durante las mediciones de matrices se detectaron dos duraciones
negativas y una duración positiva anómala. Se sustituyó el reloj
utilizado por \texttt{std::chrono::steady\_clock}, se recompiló
el programa y se repitieron únicamente los tres casos afectados:
Naive para las matrices densas D10 de tamaño 1024, muestras a y b,
y Strassen para las matrices densas D0 de tamaño 256, muestra b.
Las mediciones anteriores de esos casos fueron reemplazadas por
las nuevas; las demás mediciones se conservaron.
